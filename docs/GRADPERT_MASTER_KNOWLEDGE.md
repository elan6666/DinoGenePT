# Complete GraD-Pert knowledge corpus

## Scope

This experiment changes only the text supplied to the same
`doubao-embedding-vision` endpoint. It does not train or run GraD-Pert.

The frozen master allowlist contains 17,730 exact, case-sensitive labels:

- five canonical GraD-Pert graph-axis union: 13,759;
- unique perturbation targets: 2,469, all inside that graph union;
- fixed GGI evaluation universe: 10,870;
- graph/GGI overlap: 6,899.

Eight case-paired labels are retained because GraD-Pert exact graph identity
and the uppercase GGI protocol are separate contracts. Vector generation uses
`--preserve-gene-case`; GGI evaluation still applies its original uppercase
matching.

For the fixed GGI universe, vector selection now prefers an exact requested
label before considering a unique case-insensitive fallback. This prevents a
mixed-case graph label from silently overwriting its uppercase GGI counterpart.
The eight collision groups are listed in the final vector audit receipt.

## Progressive conditions

1. `Seed-GO-Protein`: completed NCBI + UniProt base, bounded GO-EXP, reviewed
   UniProt structured fields, and InterPro entry names.
2. `Seed-GO-ProteinPathway`: condition 1 plus human Reactome pathway names and
   direct human SIGNOR causal relations.
3. `Seed-GO-ProteinPathway-HPA`: condition 2 plus available Human Protein Atlas
   tissue, single-cell, and subcellular summaries.

Each source section is deterministic, deduplicated, sorted, and bounded. A
missing source record leaves the prior condition's text byte-for-byte unchanged.
The builder refuses missing required source files and emits source SHA-256,
per-source gene counts, clipping counts, an enrichment fingerprint, and the
final corpus hash.

## Base coverage boundary

The master base contains 15,577 exact GenePT entries, 10 case-normalized GenePT
entries, 278 HGNC alias-to-GenePT mappings, 299 HGNC identity descriptions, and
1,566 graph-label identity-only fallbacks. Identity-only rows assert only the
observed graph label; they do not claim biological function and are not counted
as functional-source coverage.

GO-EXP adds at least one selected experimental term to 12,687 of 17,730 rows.
The protein layer adds reviewed UniProt structured text to 14,847 rows and an
InterPro section to 14,731 rows. Reactome covers 10,013 genes, direct human
protein-protein SIGNOR relations cover 4,255, and HPA covers 14,658.

The server corpus audit proves exact coverage for every condition in each
dataset: K562 5,657 graph genes/1,087 targets; RPE1 6,386/2,373; Jurkat
6,506/2,372; HepG2 6,530/2,373; Norman 5,045/102. The progressive transitions
are append-only: Protein changes 14,847 rows, Pathway changes another 10,740,
and HPA changes another 14,658. The respective unchanged rows (2,883, 6,990,
and 3,072) remain byte-for-byte identical to the preceding condition.

## Matched evaluation contract

The GGI comparison remains fixed to the same 10,870 genes, train/test pairs,
labels, pair-vector addition, per-gene L2 normalization, logistic-regression
classifier, random seed 42, and package versions used by the existing
GenePT-Seed and Seed-GO results. Accuracy, AUROC, and average precision are
reported only after exact checkpoint text-hash coverage and 17,730-row vector
coverage pass.

The final comparison is generated by `genept-seed audit-ggi-comparison`. It
hard-fails if task, classifier, normalization, pair operator, random state,
train/test counts and coverage, data/universe receipts, package version, NumPy,
or scikit-learn differ between rows. A preflight over latest GenePT, completed
Seed, and Seed-GO passes all 15 fields; the three pending conditions will be
admitted only by the same gate.

`genept-seed audit-knowledge-vectors` is the final artifact gate. It requires
the exact master label order, width 2,048, a common model, finite nonzero rows,
all 10,870 exact GGI labels, and 100% exact graph/target coverage for every
dataset before any new result enters the comparison.

GGI labels. Every graph axis and perturbation target in all five datasets has

249,630 training pairs, 20,342 test pairs, L2 normalization, pair sum,

Seed+GO but below ProteinPathway, so the result supports a bounded pathway layer
rather than a monotonic more-knowledge claim.
